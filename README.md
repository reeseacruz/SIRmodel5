# SIR Model Simulation

This code simulates the SIR epidemiological model using Python.

## Parameters
- β (transmission rate) = 0.3
- γ (recovery rate) = 0.2
- Initial population: 1000 (999 susceptible, 1 infected)

## Results
The simulation shows the classic epidemic curve with infected individuals peaking around day 40.

## Dependencies
- numpy
- scipy
- matplotlib

## How to Run
`python sir_model.py`
